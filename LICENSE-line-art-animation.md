# line-art-animation attribution (MIT)

The style `line-art-living-street` (batch b44, 2026-11-12) uses ideas from this repository by JDhruv14 (X @dhruvtwt_), and a 6-second sample that we rendered ourselves with the upstream engine:

- https://github.com/JDhruv14/line-art-animation (commit c43d698): `examples/village` served with the repository's vite setup at `?debug&capture&day=60&start=0.70`, captured with the repository's `scripts/capture.ts` at 1920×1080, 30 fps, 180 frames; scaled to 1280×720 and encoded as H.264 with a silent audio track. No code or parameters were changed.
