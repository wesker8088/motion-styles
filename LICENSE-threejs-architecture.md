# threejs-architecture-effects attribution (MIT)

The style `brick-by-brick-pagoda-build` (batch b45, 2026-11-13) uses ideas from this repository by Hailey (lhlGitHub), and a 6-second sample cut from its official demo recording:

- https://github.com/lhlGitHub/threejs-architecture-effects (commit 693ca2e): `assets/preview.mp4` (the author's 20 s screen recording of the bundled clock-tower miniature, silent), seconds 5.5–11.5, cropped 1280×740 → 1280×720 (10 px off top and bottom), re-encoded H.264 30 fps with a silent audio track. The picture content was not altered.

We rewrote the style description ourselves from the README, SKILL.md and reference notes.
