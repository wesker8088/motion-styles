  1. 下载对应 zip（免费或全量），解压得到 motion-video-styles/。
  2. 拷到用户级 skills 目录：
~/.claude/skills/motion-video-styles/
cp -R /path/to/motion-video-styles ~/.claude/skills/motion-video-styles
  1. 新开或重载 Claude Code；点名 skill：「用 motion-video-styles 做一条竖屏酷炫小样」。
  2. 若读不到：检查是否多嵌套一层，以及 SKILL.md 是否在目录根上。

常见问题

  • 只有图鉴、装不上？ 图鉴是预览；可执行内容在 zip 里的 skill 目录。请先下载免费包或解锁全量包。
  • 付费怎么拿？ 全量已支持兑换码解锁（本页上方表单）。公开小店与标价由作者确认后挂上；禁止私信索要微信/网盘，也不要相信评论区「私信发卡」。
  • 更新节奏？ 以 changelog 为准，表述为持续更新；不承诺「每天」。
  • 模型差距？ 同提示词多模型对比属作者实测观感，非第三方评测；本页不提供评测分数。
