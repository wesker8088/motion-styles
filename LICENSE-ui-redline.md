# ui-redline-walkthrough attribution (MIT)

The style `ui-redline-critique` (batch b42, 2026-11-10) uses a 6-second excerpt of the official example and ideas from this repository by rjmahesh:

- https://github.com/rjmahesh/ui-redline-walkthrough (example `examples/chat-response-redesign.mp4`, 3200×1800, 60 fps, 19.4 s; commit a343122): excerpt 0.5–6.5 s.

We rewrote the style description ourselves. Our changes: excerpted to 6 seconds, cropped to the central 2160×1215 region (x 790, y 60), scaled to 1280×720 at 30 fps, silent audio track added (the upstream example has no audio).
