# root-word-animation attribution (MIT)

The style `root-word-line-ball` (batch b50, 2026-11-18) is based on this skill by the root-word-animation contributors:

- https://github.com/dongtaowei54-sys/root-word-animation (main e6b3a97): `SKILL.md`, `references/*.md`, `assets/base.html`, `examples/ced`, `scripts/build-root.js`, `scripts/render.js`.

We rewrote the style description ourselves. The upstream repository has no finished film, so the 6-second sample clip is our own render: `build-root.js` on `examples/ced` (no TTS run; voice durations already in design.json), then the upstream `render.js` (Playwright Chromium, 375×667 viewport at 2× device scale, 30 fps), frames 675–854, scaled to 720×1280 H.264, no audio. Pages and scripts unchanged. The bundled `dict/词根词典.csv` was not used or redistributed by us; its English definitions appear to come from an external dictionary whose source is not stated.
