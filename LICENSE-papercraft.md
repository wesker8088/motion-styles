# papercraft attribution (MIT)

The style `popup-cardstock-world` (batch b54, 2026-11-22) is based on https://github.com/xikhar/papercraft by Shikhar (main 5eea4eb, v0.6.0). Its 6-second sample was rendered by us, unchanged, with the repository's own capture script and the bundled countryside example: `python3 scripts/capture.py assets rise:video=6,30 --page templates/popup-3d/index.html --size 1280x720`, then re-encoded as H.264 with a silent track. Style description rewritten by us.
