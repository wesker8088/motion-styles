# ai-iso-skill (iso-figure) attribution (MIT)

The style `iso-figure-hairline-plate` (batch b50, 2026-11-18) is based on the iso-figure skill by Tolga Cohce:

- https://github.com/MrBongoC/ai-iso-skill (main 44b4da7): `skills/iso-figure/SKILL.md`, `examples/desk-synth.html`, `docs/desk-synth.gif`.

We rewrote the style description ourselves from the SKILL.md and examples. The 6-second sample clip is the upstream `docs/desk-synth.gif` (0.5–6.5 s), scaled to 720 px high and padded left/right with the page colour #0C0E0E to 1280×720, 24 fps H.264, no audio; the picture itself is unchanged.
