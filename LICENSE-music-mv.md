# music-mv (Win-Hao/music-mv) attribution (MIT)

The style `couple-story-mv` (batch b28, 2026-10-27) takes ideas from https://github.com/Win-Hao/music-mv . Its sample is the first 6 seconds of the README preview `docs/mv-seasons.gif` (480×270, 12 fps, silent), taken from one of the author's own MVs made with this workflow. We rewrote the style description ourselves. Our changes: cut to 6 seconds, upscaled to 1280×720, re-encoded as H.264 at 30 fps with a silent AAC track added. Upstream NOTICE.md: the square characters in `docs/mv-*.gif` are an unofficial fan drawing of Clawd, the Claude Code character designed by Anthropic (no affiliation or endorsement; Claude / Claude Code / Clawd trademarks and character belong to Anthropic); the lyrics shown belong to the original songwriters. The sample is kept only as a style reference — when making a film in this style, use your own characters and licensed music.
