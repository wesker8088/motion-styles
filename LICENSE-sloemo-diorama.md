# sloemo01/diorama attribution (MIT)

The style `white-slab-pixel-diorama` (batch b46, 2026-11-14) uses ideas from this repository by Nehal Kanak (Sloemo01), and a 6-second sample cut from its official showcase capture:

- https://github.com/sloemo01/diorama (commit c790df5, 2026-11-07): `media/bank-job.mp4` (2164×2160, 60 fps, 48.1 s, "Bank job" diorama), seconds 18–24, cropped around the slab, scaled to 1024×768, re-encoded H.264 30 fps. **Audio removed**: the repository does not state a licence or credits for the soundtrack or for the third-party 3D assets (the README names CC0 / CC-BY libraries such as Quaternius, Kenney and Poly Pizza as sourcing options for builds with this playbook, but does not list which assets are in each showcase scene), so only the picture is used. The picture content was not altered.
- Showcase scenes named after existing characters (e.g. `pikachu-vs-charizard`) were not used; they involve third-party trademarks.
