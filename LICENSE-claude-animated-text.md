# claude-animated-text (字會動 64 式) attribution (MIT)

The style `horror-caption-type` (batch b50, 2026-11-18) is based on the horror group (57–64) of this repository by pound (POUND0423):

- https://github.com/POUND0423/claude-animated-text (main ac869e4): `index.html`, `prompts.txt`, `render.py`, `mp4/8_恐怖片/*.mp4`.

We rewrote the style description ourselves from the README, prompts.txt and the official MP4s. The 6-second sample clip is a straight concatenation of 2-second excerpts of three official MP4s (57 Dying-bulb 4.6–6.6 s, 61 Corrupt 1.6–3.6 s, 63 Flashlight 2.0–4.0 s), scaled to 1280×720 24 fps H.264; the upstream clips have no audio. The lettering in the clips uses Noto Serif TC / Noto Sans TC (SIL Open Font License).
