# paper-reel attribution (MIT)

The style `voice-clocked-paper-mascot-reel` (batch b45, 2026-11-13) uses ideas from this repository by Haider Farooq, and a 6-second sample cut from its official example reel:

- https://github.com/haiderfarooq3/paper-reel (commit 9c5bc57): `docs/demo.mp4` (720×1280, 23.3 s, 30 fps; local Kokoro voice + code-synthesised lo-fi bed, about the khan-explainer skill), seconds 12.0–18.0, re-encoded H.264 30 fps + AAC. The picture content was not altered.
- The repository vendors its renderer / kit core from cth9191/animate (MIT, © 2026 cth9191; see LICENSE-cth9191-animate.md); Kokoro (Apache-2.0), whisper.cpp (MIT) and Playwright (Apache-2.0) are installed separately.
- The orange box mascot in the demo is the Claude Code mascot; the upstream README states the project is not affiliated with or endorsed by Anthropic and that Claude is an Anthropic trademark. Use your own original mascot in real work.

We rewrote the style description ourselves from the README, SKILL.md and references/style.md.
