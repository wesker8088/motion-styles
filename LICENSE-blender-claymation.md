# blender-claymation attribution (MIT)

The style `clay-stopmotion-tabletop` (batch b46, 2026-11-14) uses ideas from this repository by angrypenguinpng, and a 6-second sample **rendered by this library with the upstream scripts**:

- https://github.com/angrypenguinpng/blender-claymation-skill (commit 0be7cc0, 2026-09-24): `examples/igloo.py` + `scripts/claylib.py` run unchanged with Blender 4.2.3 headless (`--range 110 181 --res 960 540 --samples 24`, Cycles on CPU), then encoded with the upstream `scripts/encode.sh` filter chain (12 fps frames → 24 fps, grain + vignette). No audio.
- The repository says it was inspired by Alex Albert's post https://x.com/alexalbert__/status/2102458348511879448 ; no footage from that post was used.

We rewrote the style description ourselves from README.md, SKILL.md and references/look-guide.md.
